## Was Phase 1e gelöst hat (das eigentliche Ziel)

E1/E2 scheiterten **nicht** an der Hypothese, sondern an der
Stichprobengröße: `exit_replay_bars` allein = ~1 Jahr → n < 200 im
40 % Holdout (E1: 0 Signale wegen Trendfilter, E2: n < 200).

**Befund:** `data/backtest_cache` liefert 2021-06-01 → 2026-08-21
(~5,25 Jahre). Die **Union** aus `exit_replay_bars` + `backtest_cache` +
`ohlcv_daily` = 310 Titel, **237 mit ≥250 gemergten Tageskerzen**.
Darauf sind RSI(14)<30-Signale endgültig entscheidbar:

| | E2 (1 Jahr) | E3 (Union, 5,25 J) |
|---|---|---|
| Titel ≥250 Bars | 211 | **237** |
| RSI<30 Signale (mit 10d-Abdeckung) | ~100 | **837** |
| **n im 40 % Holdout** | < 200 (nicht entscheidbar) | **270** ✓ |

→ **n ≥ 200 erfüllt.** Die Datenbasis-Einschränkung ist gelöst. Die
Union-Historie wird Standard für alle Folge-Hypothesen.

- **E3 wird nicht umgesetzt.** Keine RSI<30-Signale in den Gate-Scope.
